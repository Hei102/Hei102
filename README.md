## 🚀 Featured Project

### FinMate — AI 财经学习与财报 RAG 系统

一个面向财经学习场景的全栈 AI 应用，目前正在整理后准备公开。

- 支持用户注册登录、收藏资产和多会话 AI 对话
- 使用 MySQL 保存业务数据，MongoDB 保存聊天记忆
- 接入财经行情、新闻与上市公司财报数据
- 支持财报 PDF 解析、分块、向量索引与限定文档检索
- 回答附带真实检索片段和 PDF 页码链接，便于人工核验
- 包含分块、检索过滤、用户隔离、失败重试等自动化测试

**Core Stack:** Spring Boot · LangChain4j · MySQL · MongoDB · Qdrant · JavaScript
